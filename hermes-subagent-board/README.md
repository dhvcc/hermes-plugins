# hermes-subagent-board

A pinned Telegram widget that shows your last background subagents. It is one message, edited in place, never re-sent.

- **Running:** a progress ring, start time, and time left. The ring turns red once a subagent is overdue or needs attention. A line warns when it has been stuck in one command for 10+ minutes.
- **Finished:** start–end and duration. Next to it, when the answer reached the chat ("replied 07:20"), or **no reply** in red when the agent finished but nothing was delivered within 15 minutes.
- **Titles:** generated by Hermes' own title generator (`auxiliary.title_generation`), the same one that names threads.
- **History:** survives gateway restarts.

ETA and the "needs attention" state come from [hermes-delegation-clock](../hermes-delegation-clock) when it is installed. Without it, the board shows elapsed time only.

The widget uses [Bot API widgets](https://core.telegram.org/bots/api#sendwidget). They work in private chats only, and not every Telegram client renders them yet. Clients that don't, for example the macOS app at the time of writing, show just the caption.

## Install

```sh
hermes plugins install dhvcc/hermes-plugins/hermes-subagent-board
hermes plugins enable hermes-subagent-board
```

Restart the gateway. It needs `TELEGRAM_BOT_TOKEN`, which the Telegram gateway already has.

## Settings

All settings go under `plugins.entries.hermes-subagent-board.settings`.

| Key | Default | Meaning |
|---|---|---|
| `language` | `en` | `en` or `ru` |
| `rows` | `6` | Subagents on the board |
| `refresh_s` | `30` | Refresh interval |
| `pin` | `true` | Pin the board |
| `hang_alert_min` | `10` | Minutes in one command before the "stuck" line shows |
| `reply_window_min` | `15` | How long to wait for the answer before showing "no reply" |
| `gateway_only` | `true` | Run only inside the gateway process |
